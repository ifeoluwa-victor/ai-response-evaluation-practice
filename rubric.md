# Scoring Rubric

Each answer gets a score from 1 to 5 on four criteria. The total is out of 20.

## 1. Factual accuracy
| Score | Meaning |
|---|---|
| 5 | All claims are correct and can be checked |
| 4 | Correct, with one tiny imprecision that does not mislead |
| 3 | Mostly correct, with one noticeable error or vague claim |
| 2 | Several errors, or one serious error |
| 1 | Mainly wrong or invented |

## 2. Relevance
| Score | Meaning |
|---|---|
| 5 | Answers exactly what was asked |
| 4 | Answers the question with a little unneeded material |
| 3 | Partly on topic and drifts |
| 2 | Mostly off topic |
| 1 | Does not address the question |

## 3. Completeness
| Score | Meaning |
|---|---|
| 5 | Covers everything the question needs |
| 4 | Misses one minor point |
| 3 | Misses a notable point |
| 2 | Covers only a small part |
| 1 | Almost nothing useful |

## 4. Instruction-following
| Score | Meaning |
|---|---|
| 5 | Follows every instruction (format, length, limits) |
| 4 | One small slip |
| 3 | Follows some instructions and ignores one clear one |
| 2 | Ignores most instructions |
| 1 | Ignores the instructions entirely |

## Rules I use
- I check facts first. A confident wrong answer does not get credit for sounding good.
- If a question says "use only the text", anything not in the text is an unsupported claim.
- Saying "the text does not say" is correct when the text really lacks the answer.
- The preferred answer is the one with the higher total. If totals are tied, accuracy decides.
