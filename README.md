# AI Response Evaluation Practice

A beginner project where I practise comparing two AI-written answers to the same question and scoring them with a fixed rubric.

> **AI disclosure:** I used Claude (Anthropic) to help draft the starting files, including the example answers and first score drafts. I review each example against the rubric, check facts, and edit scores and reasons where I disagree.
> **Originality:** All exercises are original practice questions. They are not copied from any company's hiring test or confidential material.

## What this project shows
- Checking facts in AI answers
- Reading instructions closely (format, length, limits)
- Noticing invented or unsupported details
- Writing short reasons for each score

## Scoring method
Each answer is scored from 1 to 5 on four criteria:
1. Factual accuracy
2. Relevance
3. Completeness
4. Instruction-following

The total is out of 20. The answer with the higher total is preferred. If totals are tied, accuracy decides.

## Files
- `rubric.md`: what each score from 1 to 5 means
- `examples-part-1.md`: practice examples 1 to 5
- `examples-part-2.md`: practice examples 6 to 10 (including two healthcare examples)
- `scoring-sheet.csv`: all scores in one table, for Excel or Google Sheets
- `common-mistakes.md`: mistakes I try to avoid when evaluating
