# Common Evaluation Mistakes and How I Avoid Them

| Mistake | How I avoid it |
|---|---|
| Preferring the longer or more polished answer | I score each criterion separately and check accuracy first |
| Trusting a confident tone | I check the claim against a source |
| Missing invented details | I compare every name, number and date with the given text |
| Giving credit for a correct side detail when the main answer is wrong | I judge the main answer first |
| Ignoring small format instructions | I list every instruction before I score |
| Using my own opinion as fact | I use a reliable source and note it |
| Marking "the text does not say" as a bad answer | It is correct when the text really lacks the answer |
| Scoring too fast | I read both answers twice before I score |
| Always favouring Answer A or Answer B | I check that my choices are not following a pattern |
| Scoring the same kind of error differently each time | I follow the same rule for each criterion every time |
